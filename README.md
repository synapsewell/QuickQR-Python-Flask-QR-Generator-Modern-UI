# QuickQR - Modern Python Flask QR Code Generator Script (Dark UI)

A premium, ultra-fast, and secure QR Code Generator built with Python (Flask) and a modern Tailwind-inspired Dark UI. Perfect for launching your own micro-SaaS or dropping it into an existing web application.

## ⚡ Features
- **5 Formats Built-in:** Website Link, Instagram, TikTok, PayPal Pay, and vCard Electronic Business Cards.
- **Dynamic Live Customization:** Change QR code colors and background colors on the fly with real-time updates.
- **Ultra-Fast Generation:** Powered by `segno`, codes are generated instantly with zero server lag.
- **One-Click Download:** High-quality PNG download directly to the user's device.
- **Clean SaaS UI:** Cyberpunk-inspired aesthetic that looks expensive.
